# Lume & Luxe – Textile E-commerce Platform

## Overview

Lume &amp; Luxe is a strategic e-commerce solution designed to streamline the consumer funnel for the textile industry. Built with a Flask (Python) modular backend and JWT-secured authentication, the platform focuses on solving the "Personalization Gap" in fashion through a unique Fabric Customization Engine.


## Key Features

* User Authentication (JWT-based secure login/signup)
* Product Browsing by Category (Men, Women, Kids)
* Fabric Customization for personalized shopping experience
* Cart Management & Order Tracking
* Razorpay Payment Gateway Integration (Test Mode)

## Product Thinking

* Focused on improving **user journey from discovery → cart → checkout**
* Introduced **fabric customization** to increase user engagement and personalization
* Designed secure checkout flow to reduce drop-offs and improve trust

## Metrics Considered

* Conversion Rate (browse → purchase)
* User Engagement (customization usage)
* Cart Abandonment Rate

## Tech Stack

* Backend: Flask, SQLAlchemy
* Database: MySQL
* Frontend: HTML, CSS, JavaScript
* Auth: JWT
* Payments: Razorpay (Testmode)
