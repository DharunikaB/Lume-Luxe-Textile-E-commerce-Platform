# 🛍️ Lume & Luxe – Textile E-Commerce Platform

## 📖 Overview

Lume & Luxe is a full-stack textile e-commerce platform designed to enhance the online shopping experience through secure authentication and personalized fabric customization. The application follows a modular Flask backend architecture with JWT-based authentication and integrates Razorpay (Test Mode) for secure payment processing.

The project was developed with a product-oriented approach, focusing on improving the customer journey from product discovery to checkout while addressing the personalization gap in textile shopping.

---

## ✨ Key Features

- 🔐 JWT-based User Authentication
- 👕 Product Browsing by Category (Men, Women & Kids)
- 🎨 Fabric Customization Engine
- 🛒 Shopping Cart Management
- 📦 Order Tracking
- 💳 Razorpay Payment Gateway Integration (Test Mode)
- 🏗️ Modular Flask Backend Architecture

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/your-username/lume-luxe.git
cd lume-luxe
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Configure Environment Variables

Sensitive credentials are **not** stored in this repository.

Create a `.env` file using the provided `.env.example` template.

Example variables:

```env
SECRET_KEY=
JWT_SECRET_KEY=
MYSQL_HOST=
MYSQL_USER=
MYSQL_PASSWORD=
MYSQL_DATABASE=
RAZORPAY_KEY_ID=
RAZORPAY_KEY_SECRET=
```

### Run the Application

```bash
python app.py
```
